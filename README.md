# Israelsaba Tap

## How do I install these formulae?

`brew install israelsaba/tap/<formula>`

Or `brew tap israelsaba/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "israelsaba/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
